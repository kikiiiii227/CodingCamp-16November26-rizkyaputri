Halo Kiro, tolong catat aturan dan spesifikasi proyek To-Do List Life Dashboard ini ke dalam folder .kiro (steering):

Technical Constraints:
- HTML for structure, CSS for styling, Vanilla JavaScript (no frameworks like React, Vue, etc.), no backend server.
- Use browser Local Storage API (all data stored client-side only).
- Must work in modern browsers.

Non-Functional Requirements:
- Clean, minimal, user-friendly aesthetic, fast load time, responsive UI.

Required Features (MVP):
- Greeting: current time, date, and time-based greeting.
- Focus Timer: 25-minute timer with start, stop, and reset buttons.
- To-Do List: add, edit, mark as done, delete tasks (saved in Local Storage).
- Quick Links: buttons to open favorite websites (saved in Local Storage).

Folder Rules:
- Only 1 CSS file inside css/
- Only 1 JavaScript file inside js/

Challenges (All 5 selected):
- Light / Dark mode
- Custom name in greeting
- Change Pomodoro time
- Prevent duplicate tasks
- Sort tasks
